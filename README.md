# Data Science & Machine Learning: Normal & Standard Normal Distribution

This repository contains practical implementations, visual representations, and statistical analysis of **Normal Distribution (ND)** and **Standard Normal Distribution (SND)** using Python.

---

## 📌 Project Overview

This module covers essential concepts in continuous probability distributions, statistical normalization, and data transformation techniques commonly used in Data Science and Machine Learning workflows.

### Key Concepts Covered
* **Normal Distribution ($\mu, \sigma$):** 
  * Probability Density Function (PDF) & Cumulative Distribution Function (CDF)
  * Visualizing Gaussian distributions and bell curves under varying parameters
* **Standard Normal Distribution ($\mu = 0, \sigma = 1$):** 
  * Data standardization via $Z$-score transformation:
    $$Z = \frac{X - \mu}{\sigma}$$
* **Statistical Analysis:** 
  * Computing probabilities, percentiles, confidence intervals, and $Z$-score empirical rules ($68-95-99.7$ rule).
